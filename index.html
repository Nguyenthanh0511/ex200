Sources and version notes

Scope source: Official RH124 course page and Official RH134 course page. Both public outlines state that the current courses are based on Red Hat Enterprise Linux 10.0.

Image mode: Red Hat documentation: Using image mode for RHEL.

Additional RH124 research sources: Safe removal of storage devices; Configuring Ethernet connections; Managing the default gateway; Using OpenSSH securely.

Kubernetes scope sources: Kubernetes Workloads; Services, Networking, and NetworkPolicy; Kubernetes Security. The 180 Kubernetes questions are original practice questions derived from current official Kubernetes documentation. They combine concept recognition, YAML interpretation, multiple-select, and troubleshooting scenarios; they are not copied certification-exam questions.

Command-level references: Each question names relevant local manual pages such as man useradd, man systemctl, man nmcli, or man semanage-fcontext. Use the manual pages on your lab system because installed command behavior matches that system's package version.
